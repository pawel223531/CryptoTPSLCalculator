# Crypto TP SL Calculator

Android trading calculator for TP/SL, ROI, risk management, profiles, history, ads, and PRO upgrade.

## Features

- LONG / SHORT calculator
- TP, SL, and ROI calculations
- leverage from x1 to x100
- supported assets: BTC, ETH, BNB, SOL, XRP, DOGE, GOLD, SILVER, OIL (CL), CUSTOM
- strategy profiles
- saved history
- risk calculator
- multilingual strings: PL / EN / ES
- AdMob banner and interstitial support
- Google Play Billing PRO upgrade support
